# Trabalho Prático de Exploração de Dados
- Este trabalho faz parte da disciplina Ciência de Dados da UFAM
  
### Descrição:
- Este projeto tem como objetivo explorar dados do ENEM 2019, com foco na cidade de São José dos Campos, analisando a qualidade dos dados, tratando valores ausentes e comparando o desempenho de alunos de escolas públicas e privadas.

### Ferramentas Utilizadas:
- Python 3
- Pandas, NumPy
- Matplotlib, Seaborn
- SciPy, Scikit-learn
